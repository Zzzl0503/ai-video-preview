# 🎬 《完蛋！我被AI包围了》系列 · POV 机位透视与布光导演台

> 零依赖纯前端单文件工具（HTML5 + Canvas 2D + 真实 35mm 针孔透视数学模型），专为多角色 AI 真人实拍风短剧（Seedream 5.5 + Seedance 2.5）提供 **精确站位排演、防遮挡质检、布光预设、1080×1920 构图底图导出与纯净提示词自动生成**。

## ✨ 核心功能

1. **实时 9:16 35mm 针孔透视取景器**
   - 精确还原 4 位角色真实身高差（大肥鱼 162cm / 小克 168cm / GPT 175cm / 哈基米 156cm）与近大远小透视比例。
   - 完整内置现代原木客厅家具坐标（橡木地板、米白地毯、浅灰三人布艺沙发+抱枕、矮椭圆胡桃木茶几、右侧落地窗白纱帘、右后橄榄树盆栽、沙发上方极简抽象画、后左木质客厅房门）。
2. **2D 俯视机位平面图拖拽调度**
   - 直接在俯视图中拖拽 4 位女主与 POV 摄影机位，实时调节焦距（20mm–50mm）、机位高度与俯仰角。
   - **自动防遮挡质检**：实时检测屏幕空间内前排角色肩部/头部是否遮挡后排角色脸部。
3. **纯净构图底图一键导出（1080×1920 PNG）**
   - 开启「纯净构图底图模式」隐藏所有辅助线与标注，导出 1080×1920 构图参考底图，直接搭配角色 4K 三视图喂给 Seedream 5.5 锁定纵深与比例。
4. **连续剧多集复用 & Git 版本控制**
   - 支持一键导出/导入每一集的分镜机位 JSON（存放在 `presets/` 目录），轻松管理 `EP.01`、`EP.02`... 全季机位资产。
   - **动态生成纯净版 Seedream 5.5 首帧提示词**：自动根据当前真实坐标（米）、左中右方位、站坐姿态、家具与色温布光输出干净无冗余约束的提示词。

## 🚀 快速使用与发布到 GitHub Pages

本项目为纯静态前端，**无需安装 Node.js 或任何依赖**：

1. **本地直接打开**：双击 `index.html` 即可在浏览器离线运行。
2. **推送到你的 Git 仓库**：
   ```bash
   git init
   git add .
   git commit -m "feat: add POV blocking and lighting studio for EP.01+"
   git branch -M main
   git remote add origin <你的仓库地址>
   git push -u origin main
   ```
3. **开启 GitHub Pages 在线版**：进入仓库 `Settings -> Pages -> Source` 选择 `main` 分支根目录，保存后即可获得随时在线访问的剧组导演台链接。

## 🎥 连续剧标准生产流（配合 Seedream 5.5 + Seedance 2.5）

1. **排机位**：在导演台拖拽好本集角色站位，确保亮起 `✅ 四人视线零遮挡`，且核心角色避开右侧/底部平台 UI 安全区。
2. **存档**：点击「导出分镜 JSON」存入 `presets/epXX_shotXX.json` 提交 Git。
3. **出底图 + 拿提示词**：点击「导出 1080×1920 构图参考图 (PNG)」并复制自动生成的「纯净首帧提示词」。
4. **合成首帧**：在 Seedream 5.5 上传 4 位女主的 4K 三视图（可选叠加构图参考底图），一步合成零穿帮的 9:16 剧集首帧。
5. **出正片**：在 Seedance 2.5 挂载「首帧图 + 角色三视图 + 干声音色参考」直出 30s 样片。
